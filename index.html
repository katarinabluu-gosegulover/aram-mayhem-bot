ARAM 봇은 친구 Discord 서버에서 ARAM Mayhem 모집, 대기열, Riot ID 연결을 관리하는 비공개 커뮤니티용 봇입니다.

사용 방법 보기 개인정보 처리방침

WHAT IT DOES

모집에 필요한 기능만 담았습니다.

01

5인 모집

슬래시 명령으로 모집을 만들고 참가·취소 버튼으로 정확히 5명까지 관리합니다.

02

대기열 자동 승격

정원이 차면 대기열에 등록되고, 참가자가 취소하면 순서대로 자동 참가 처리됩니다.

03

재시작 복구

봇이 다시 시작되어도 진행 중인 모집의 버튼과 상태를 복구합니다.

04

운영 권한

모집 작성자와 서버 관리 권한자가 모집을 종료하거나 취소할 수 있습니다.

RIOT ID CONNECTION

원하면 Riot ID를 연결할 수 있습니다.

/riot 등록 게임이름#태그를 사용하면 Riot Account API로 계정 존재 여부를 확인하고 Riot ID와 PUUID를 Discord 계정에 연결합니다. 연결된 정보는 /riot 내정보에서 본인만 확인할 수 있고, /riot 해제로 즉시 삭제할 수 있습니다.

현재 기능은 전적, 랭크, 게임 플레이 데이터 또는 Riot 계정 비밀번호를 수집하지 않습니다.

HOW TO USE

Discord에서 바로 시작하세요.

  1. 1
    모집 만들기/aram 모집 title:오늘 10시 아수라장 duration_minutes:90
  2. 2
    참가 또는 대기열 참여

    모집 메시지의 버튼을 누릅니다.

  3. 3
    필요하면 Riot ID 연결/riot 등록 riot_id:게임이름#태그
